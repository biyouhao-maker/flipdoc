# FlipDoc 轻翻 · 微信翻页画册工具

把日常完成的 **PDF、Word (.docx)、PPT (.pptx)、Markdown (.md / .txt)** 以及**多张图片**，一键转化为适合微信浏览的 **3D 仿真翻书 + 手机丝滑滑动** 电子画册。

## 核心特性

- **极简拖拽工作台**：首页即拖拽上传区，拖入文件自动解析封面、提取目录、生成画册链接与二维码。
- **双模式翻页体验**：
  - **3D 仿真翻书模式**：真实纸张折角与阴影（桌面端竖版文档自动双页展开，手机与 16:9 演示稿单页清晰翻折）。
  - **丝滑滑动模式**：专为微信手机端打造，支持跟手左右滑动、**双指缩放（1x–3.5x）**、**双击放大**与放大后拖拽。
- **完整阅读辅助**：自动提取章节目录（PDF 书签 / Word 与 Markdown 标题 / PPT 幻灯片标题）、全册缩略图快速跳页、进度条拖动、深色画廊/暖色书桌背景切换、精排纸张主题切换。
- **多格式智能转换**：
  - **PDF**：原版高清渲染（内置本地 PDF.js Worker 与中文 CMap 字体映射，无需外网 CDN）。
  - **Word (.docx)**：检测到本机 LibreOffice 时默认高保真还原版式，也可一键切换「手机精排重排」模式。
  - **PPT (.pptx)**：检测到 LibreOffice 时无损还原 16:9 演示稿并提取每页标题作目录；无 LibreOffice 环境自动降级为内置轻量幻灯片解析。
  - **Markdown / TXT**：杂志级中英文混排、代码高亮、表格与防孤立标题智能断页。
  - **多图画册**：一次拖入多张图片自动 WebP 压缩优化为图集画册。
- **微信分享与权限保护**：
  - 一键生成 **900×1360 高清微信分享海报**（封面 + 标题 + 摘要 + 二维码），无需公众号即可发群/朋友圈长按扫码。
  - 服务端动态注入 `Open Graph` 封面与摘要，并预留微信公众平台 JS-SDK 签名接口。
  - 支持 **访问密码（服务端签名校验）** 与 **链接有效期（24 小时 / 7 天 / 30 天 / 永久）**。
  - 支持 **一键导出分页 PNG 卡片图**，未部署公网前也能直接发图进微信。
- **PWA 类 App 体验**：手机浏览器「添加到主屏幕」即可像原生 App 一样全屏使用。

## 快速启动

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 即可使用。首次启动会自动生成 3 份演示样册（杂志精排指南、16:9 演示 PDF、加密保护样本，演示密码 `8888`）。

### 手机微信同 Wi-Fi 扫码预览

服务默认监听 `0.0.0.0:3000`，点击任意画册上的 **「分享」**，切换到 **「同 Wi-Fi 手机扫码」**，直接用手机微信扫一扫即可真机体验翻页效果。

## 生产构建与部署

```bash
npm run build
npm run start
```

参考 `.env.example` 配置 `NEXT_PUBLIC_SITE_URL`、`STUDIO_PASSCODE`（建议公网开启）与可选微信 JS-SDK 参数。数据默认保存在本地 `data/` 目录（SQLite + 上传文件）。
